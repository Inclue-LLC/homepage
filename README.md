# 合同会社インクルー 会社ホームページ

会社紹介資料（COMPANY PROFILE）の内容をもとにした静的なコーポレートサイトです。ビルドは不要で、HTMLファイルをそのまま公開できます。

## ページ構成

| ファイル | ページ | 主な内容 |
|---|---|---|
| `index.html` | トップ | メインビジュアル、写真、About us、事業内容、キャラクター一覧、プラットフォーム一覧、最近の取り組み、Contact |
| `business.html` | 事業内容 | キャラクター展開事業（ライセンス／POP UP／コラボ）、中国展開、プラットフォーム事業（Gachafy／POP BASE） |
| `works.html` | 最近の取り組み | POP UP・ライセンス・コラボ・中国展開・プラットフォームの事例（カテゴリ絞り込み付き） |
| `company.html` | 会社概要 | 会社情報、拠点（地図）、沿革 |
| `contact.html` | お問い合わせ | ご相談内容の例、お問い合わせフォーム |

```
assets/css/style.css  スタイル
assets/js/main.js     スマホメニュー、スクロール演出、お問い合わせフォーム
assets/img/           画像（WebP）、OGP画像、ファビコン
```

ヘッダー・フッターは各HTMLに同じものが入っています。メニューや住所を変えるときは5ファイルすべてを修正してください。

## お問い合わせフォームについて

サーバー不要で動くよう、送信ボタンを押すと閲覧者のメールソフトが起動し、入力内容入りのメールが作成される仕組みです。
フォームから直接送信したい場合は、Formspree などのフォーム送信サービスや自社サーバーの送信プログラムに差し替えてください。

## 確認方法

`index.html` をブラウザで開くか、ローカルサーバーを起動して http://localhost:8000 を開きます。

```bash
python3 -m http.server 8000
```

## 公開前のチェック

- `og:image` を絶対URL（`https://〜/assets/img/ogp.jpg`）に変更
- 掲載するメールアドレス、キャラクター画像（コラボ画像を含む）の掲載可否を確認
